DeviceIOT8266

Main sketch: DeviceIOT8266.ino

Runtime: official ESP8266 Arduino core only (no esp8266RTOSArduCore / FreeRTOS).
Periodic work is organized as cooperative services in loop() and the ESP8266
core recurrent callback scheduler; see docs/BUILD_MODES.md.

The firmware retains only DHT11, A0 ADC, and LoRa. It uses a non-blocking Wi-Fi reconnect strategy and a configuration AP fallback. See docs/BUILD_MODES.md for dependencies and pin assignments.
