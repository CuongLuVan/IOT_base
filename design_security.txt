5. Luồng server gửi lệnh xuống thiết bị

Chiều ngược lại cũng tương tự:

  │
  │ command = TURN_ON
  ▼
Ascon-AEAD128
  │
  │ K_session_18
  ▼
ciphertext + tag
  │
  ▼
MQTT Broker
  │
  ▼
Device
  │
  │ derive K_session_18
  ▼
Ascon-AEAD128 decrypt
  │
  ├──────── tag OK ────────► TURN_ON
  │
  └──────── tag FAIL ──────► DROP
